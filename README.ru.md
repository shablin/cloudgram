Этот шаблон стремится предоставить комфортный опыт при создании Telegram-ботов на 
платформе Telegram Serverless. Проект вдохновлён известными существующими библиотеками 
для разработки ботов и претендует стать лёгким и удобным инструментом

## Возможности
> [!WARNING]
> На данный момент часть возможностей не реализована. Это лишь общее 
> описание предполагаемых возможностей проекта, которые будут внедрены по ходу 
> разработки

- **Система команд:** реестр команд и обработчики
- **Система сценариев:** контроль состояния, возможность создавать нелинейные сценарии взаимодействия с ботом
- **Инструменты форматирования**: поддержка удобного форматирования, включая Rich Messages
